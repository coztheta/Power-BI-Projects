# Power BI Business Intelligence Portfolio

Welcome to my comprehensive data analysis and business intelligence showcase. This repository hosts a collection of advanced, domain-specific Power BI dashboards. All projects are stored in the modern **Power BI Project (.pbip)** developer format to enable clean version control and metadata tracking.

## 📊 Dashboard Directory & Portfolio Breakdown

| Domain / Project | Core Metrics & Analysis Focus | Technical Features |
| :--- | :--- | :--- |
| **Banking Customer Churn** | Explores customer attrition patterns, credit score impacts, demographics, and risk factors to drive retention strategies. | DAX tracking measures, churn rate indicators, demographic clustering. |
| **Blinkit Analysis** | Evaluates quick-commerce delivery performance, order fulfillment fulfillment metrics, product category distributions, and localized sales. | Time-intelligence metrics, dynamic item categorizations. |
| **Electric Vehicle (EV) Insights** | Tracks global and regional EV adoption rates, battery efficiency dynamics, manufacturing trends, and environmental impact metrics. | Geospatial maps, trend line forecasting, multi-page layout links. |
| **Electronic Store Operations** | Monitored consumer electronics inventory turnover, product line profit margins, and performance evaluations across tech categories. | Matrix hierarchies, conditional variance formatting. |
| **Global Superstore** | A high-level corporate dashboard tracking international logistics, global shipping delays, multi-currency revenue, and global profitability. | Advanced parameters, regional filters, breakdown trees. |
| **Retail Store Performance** | Drills down into traditional brick-and-mortar storefront KPIs, basket analysis, average order values (AOV), and foot traffic conversion rates. | Dynamic tooltips, basket size analysis, cross-filtering. |
| **Sales Performance Pipeline** | Standard operational revenue tracking analyzing target vs. actual metrics, top-performing sales executives, and pipeline forecasting. | Gauge indicators, KPI cards, custom date hierarchies. |
| **Trading & Market Analysis** | Examines historical stock or asset movements, price volatility, volume analysis, and portfolio performance trends. | Candlestick visualizations, moving averages, rolling sum calculations. |

## 🛠️ Tooling & Technical Skills Demonstrated
* **Data Modeling:** Star Schema configurations, fact/dimension relationship mapping, and row-level security (RLS).
* **Data Transformation:** Power Query (M Language) data cleaning, schema definitions, custom column transformations, and merging/appending datasets.
* **Analytical Computations:** Advanced DAX programming (Calculated Columns, Measures, Time Intelligence functions like `SAMEPERIODLASTYEAR`, and `CALCULATE` logic modifiers).
* **Architecture:** Formatted entirely as `.pbip` for production-grade CI/CD and developer environment synchronization.

## 🚀 How to Explore the Reports Locally
Because these files are saved in the developer-centric `.pbip` format, you can easily inspect the raw configuration files right here on GitHub, or download them to open locally:
1. Clone this repository to your computer.
2. Open **Power BI Desktop**.
3. Go to **File** > **Open report** > **Browse reports** and select the `.pbip` file from the corresponding project folder.
